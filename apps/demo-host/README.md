# demo-host

React 19 dashboard that hosts the Svelte admin remote under `/admin`, using React Router and `@module-federation/runtime`. Scaffolded with `create vite` (react-ts).

The integration is [`src/AdminRoute.tsx`](src/AdminRoute.tsx) and [`src/loadAdminRemote.ts`](src/loadAdminRemote.ts). See the [root README](../../README.md) to run it.
